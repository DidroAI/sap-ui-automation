      Set up in a minute

      Your agent works in SAP in this Chrome, in the systems you add.

      1. Set up this computer

        In a terminal, run this. It installs the helper and adds the tool to your agent apps. Then restart Chrome and your agent app.

        npx -y sap-ui-automation setup --extension

      2. Pair Chrome with the helper
        One click. After this, only your agent on this computer can use the extension.

        Pair with a code instead

        Run npx -y sap-ui-automation extension pair in a terminal, then paste the code it prints.

      3. Add your SAP systems
      4. Ask your agent
